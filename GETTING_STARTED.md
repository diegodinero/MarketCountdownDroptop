## 🚀 Quick Installation

### Step 1: Copy the App Folder
Copy the `MarketCountdown` folder from this project to:
```
C:\Program Files\Droptop Four\@Resources\GlobalSettings\0_Community\CommunityApps\
```

**Result should be**: 
```
C:\...\CommunityApps\MarketCountdown\
```

### Step 2: Restart Droptop
1. Right-click Droptop in taskbar
2. Click "Exit"
3. Reopen Droptop
4. Wait 10 seconds

### Step 3: Enable in Settings
1. Click Droptop settings (⚙️ gear icon)
2. Go to "Apps" section
3. Check "Market Countdown"
4. Icon appears in Droptop bar ✅

## ✨ What This Does

Displays forex market status in your Windows taskbar:
- 🕐 Current time in each market
- 📊 Market status (OPEN/CLOSED)
- ⏱️ Countdown to market open
- 📈 Session progress percentage
- 🗺️ 4 markets: London, New York, Sydney, Tokyo

## ⚙️ Requirements

- **Droptop Four** v4.0+ ([Download](https://www.droptopfour.com))
- **Rainmeter** v4.3+ ([Download](https://www.rainmeter.net))
- **Windows** 7 SP1 or later
