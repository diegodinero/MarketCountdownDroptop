🚀 3-STEP INSTALLATION
═══════════════════════════════════════════════════════════════

1. COPY MarketCountdown folder to:
   C:\Program Files\Droptop Four\@Resources\GlobalSettings\0_Community\CommunityApps\

2. RESTART Droptop:
   - Right-click Droptop in taskbar
   - Click "Exit"
   - Reopen Droptop
   - Wait 10 seconds

3. ENABLE THE APP:
   - Click Droptop settings (gear icon)
   - Go to "Apps"
   - Check "Market Countdown"
   - Done! Icon appears in Droptop bar


⚙️ BASIC CONFIGURATION
═══════════════════════════════════════════════════════════════

Edit: MarketCountdown/Variables.inc

Key settings:
  Use24Hour=1         (1 = 24-hour format, 0 = 12-hour)
  IsDarkMode=0        (1 = dark, 0 = light)
  ShowAUD=1           (Change to 0 to hide Australian Dollar)
  ShowEUR=1           (Change to 0 to hide Euro)
  etc...

Most common change: Time format
  Use24Hour=1  →  shows 13:45
  Use24Hour=0  →  shows 1:45 PM

❓ QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

App doesn't appear?
  → Check folder is in correct location
  → Restart Droptop completely
  → See INSTALLATION.md for details

Wrong market status?
  → Verify Windows timezone (Settings → Time & language)
  → Ensure system time is synchronized
  → Restart the app

Wrong time displayed?
  → Edit Use24Hour in Variables.inc
  → Toggle the setting to refresh
  → Restart Droptop


🔧 CUSTOM ICONS
═══════════════════════════════════════════════════════════════

Replace PNG files in:
  MarketCountdown/Icons/          (main menu icons)
  MarketCountdown/Folder/Icons/   (submenu icons)

Requirements:
  • Format: PNG
  • Size: 32x32 pixels
  • Color: White (#FFFFFF)
  • Background: Transparent

Find icons at: flaticon.com or create your own


✨ TIPS
═══════════════════════════════════════════════════════════════

Hide Unwanted Currencies
  Set Show[CURRENCY]=0 in Variables.inc
  Example: ShowEUR=0 hides European Dollar news

Use Dark Mode
  Set IsDarkMode=1 in Variables.inc

Monitor Trading Efficiently
  Keep only markets you trade (hide others)
  Reduces visual clutter
